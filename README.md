# ⚡ KRONOS // Obsidian & Emerald Task Matrix

A futuristic, high-performance To-Do web application crafted with **React 18**, **TypeScript**, and **Tailwind CSS**. Designed in **pure pitch black (`#000000`)** with vibrant **neon emerald and matrix green** accents, glassmorphic obsidian panels, and ambient glow effects.

---

## ✨ Features

- **🎨 Obsidian & Cyberpunk Aesthetic**
  - Pure `#000000` deep obsidian background with subtle emerald grid overlay
  - Glowing neon green status indicators, badges, and focus rings
  - Glassmorphic backdrop-blur cards with responsive hover physics
  - Custom Web Audio synthesizer sound effects (offline, zero external audio assets)
  - Neon green and white confetti bursts on task completions

- **📋 Task & Mission Operations**
  - **Quick Inline Add**: Type your task in the command bar and hit Enter
  - **Comprehensive Mission Builder**: Detailed modal supporting notes, priority tiers, status, categories, subtasks, tags, and due date/time
  - **Subtask Checklist with Progress**: Interactive mini checkboxes and dynamic completion percentage bar
  - **Pin to Top**: Keep critical tasks locked to the top of your workspace
  - **Duplicate & Clone**: Quickly duplicate existing missions with a single click

- **📊 Velocity & Productivity Matrix**
  - Real-time completion velocity meter with animated glowing gradient
  - Active and pending mission counters
  - Critical/Urgent priority quick-filter alert
  - Overdue task monitor with countdown badges
  - Focus streak tracker (`🔥`)

- **🎛️ Views & Organization**
  - **List View (`1`)**: Full-width stacked view for deep focus
  - **Grid View (`2`)**: Multi-column responsive card matrix
  - **Kanban Board (`3`)**: Three interactive lanes (`To Do`, `In Progress`, `Done`) with one-click lane migration
  - Instant fuzzy search with keyboard shortcut (`/`)
  - Filter by status (`All`, `Active`, `Completed`, `Starred`)
  - Filter by Category & Priority
  - Sort by Due Date, Priority, Creation Date, or A-Z

- **💾 Data Persistence & Portability**
  - Automatic `localStorage` synchronization
  - **Export to JSON**: Full portable backup file
  - **Export to CSV**: Spreadsheet-ready export
  - **Import JSON**: Restore or merge tasks from external files
  - Factory reset to starter template

- **⌨️ Keyboard Shortcuts**
  - `N` — Initialize new mission
  - `/` — Focus search field
  - `Esc` — Close open modal or blur search
  - `M` — Toggle sound effects
  - `1`, `2`, `3` — Toggle between List, Grid, and Kanban views
  - `?` — Open shortcuts reference

## 🚀 Getting Started

The app is already running on your machine:

```bash
# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

Server URL: **`http://localhost:5173`**
